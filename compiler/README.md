# compiler — 参考实现入口（zorcc）

OQ-1 定论=方案 B（评审 3/3 通过）：过渡实现用 Rust 编写，后端走 C 代码生成；0.2.x 以 C11 后端落地首片、后续可替换。本目录即该实现的 Cargo 工程。

## L2u 合并后现状（0.3.20）：R1／R2 前端检查＋C11 后端；typed Box 8 整型宽度、f32／f64 源形态与复合承载、Box<float> 特殊值载荷、Box 常量载荷（struct／定长数组／有限浮点标量）、枚举单载荷与多字段特殊值字面量直接形式、嵌套复合中的枚举值直接特殊值形式、六个命名有限浮点常量（MAX／MIN／EPSILON）、`MIN_POSITIVE`（f64／f32）、十个整型成员（MAX_EXP／MIN_EXP／MANTISSA_DIGITS／DIGITS／RADIX × f64／f32）、单层限定枚举变体构造（`E::V(args...)`，含 `E::N()`）、Box 常量性边界定义切片（claim 固化；无新增语言能力）、`Box<enum>` 常量枚举载荷子集（标注绑定；tag＋union；不递归析构）、诊断文本层（D1 文案／D2 `Box<?>` 收敛／D3–D5 执行面与工具修正；无新增语言能力）

- `src/lexer.rs` → `src/parser.rs` → `src/check.rs`（R1 类型检查＋R2 所有权/借用检查，E1xxx／E2xxx 诊断）。
- 诊断格式（T-4 黄金文件基线，变更需 PR+QA 评审）：`zorcc: {E-code} {file}:{line}:{col}: {message}`
- 退出码：0=无诊断；1=有诊断；2=用法/读文件错误。负例在 debug/release 双 flag 下均须非零退出（CI 双模式契约）。
- 已实现诊断码：E1101/E1201/E1202/E1301/E1401/E1501/E1601/E1701/E1702/E1703/E1704（R1 §8 码表）；E1502/E2101/E2102/E2201/E2202/E2301（R2 §8 码表）。
- 已实现（L2h 合并后）：R2 所有权／借用检查（E2101／E2102／E2201／E2202／E2301；返回引用 E1502）与 box／unbox 语法。
- typed Box：8 个整型宽度（`Box<i8>`／`Box<i16>`／`Box<i32>`／`Box<i64>`／`Box<u8>`／`Box<u16>`／`Box<u32>`／`Box<u64>`）的注解构造、`println(*b)`、`unbox`／drop 与局部重赋值；`Box<f32>`／`Box<f64>` 可承载六个特殊值源形态（注解构造、`println(*b)`、移动、局部重赋值、`unbox`／drop）与有限字面量载荷；`Box<struct>`／`Box<[T;N]>` 可承载字面量常量载荷并整体打印（与同值复合打印逐字节同构）；嵌套 Box／含 Box 复合值、变量载荷、函数签名／struct 字段维持 fail-closed。
- 浮点：f32／f64 有限字面量、六个特殊值源形态（`f64::NAN`／`f64::INFINITY`／`f64::NEG_INFINITY`／`f32::NAN`／`f32::INFINITY`／`f32::NEG_INFINITY`）与 `println` 打印（`nan`／`inf`／`-inf`）；tuple／array／struct 常量成员（含既有嵌套与投影，投影仅 `println` 实参）可承载并打印；枚举单载荷变体可承载六命名特殊值并打印（`V(nan)`／`V(inf)`／`V(-inf)`；宽度由变体字段严格匹配）；多字段变体可承载特殊值字面量直接形式（任意字段位置、≥2 字段；与绑定路径逐字节同构）；嵌套复合中的枚举值可直接承载特殊值字面量（任意深度、三种外层别名；与绑定路径逐字节同构）；六个命名有限浮点常量（`f64::MAX`／`MIN`／`EPSILON`、`f32::MAX`／`MIN`／`EPSILON`）与 `f64::MIN_POSITIVE`／`f32::MIN_POSITIVE` 可按类型用于标量／绑定／`Box`／枚举／复合／多实参（A 档）；其他未列名 `::` 成员（`MIN_10_EXP`／`MAX_10_EXP`／`DIG`／`NEG_NAN` 等）仍 E1101；Box 复合含 enum（struct／array 字段）、嵌套 Box、变量载荷、反方向（特殊值／常量位于枚举自身复合载荷内，N-217／218）维持 fail-closed（`Box<enum>` 常量子集见下 L2t）；绑定路径 `V(x)`／`V(x, 1.5)`／`S { e: V(x) }` 等为既有能力；浮点算术／比较不做；非字面量 Box 载荷（变量引用／含 Box 复合值等）、隐式转换、其他 `Type::member` 维持 fail-closed。
- 整型常量成员（L2q 合并后）：十个编译期整型常量——`f64::MAX_EXP`（1024）／`f64::MIN_EXP`（-1021）／`f64::MANTISSA_DIGITS`（53）／`f64::DIGITS`（15）／`f64::RADIX`（2）、`f32::MAX_EXP`（128）／`f32::MIN_EXP`（-125）／`f32::MANTISSA_DIGITS`（24）／`f32::DIGITS`（6）／`f32::RADIX`（2）；按整数字面量语义接入：无标注默认 `i64`，有整型标注时向目标类型收敛，标量输出与同值十进制字面量逐字节一致；可用于标量／绑定／`Box<T>` 标量整型载荷（含负值）／枚举载荷／struct／数组／元组／多实参及上述位置的既有嵌套（A 档）。`MIN_EXP` 值本身为负；既有整型一元负号／算术沿用（不是新增能力）。整型成员→浮点标注：绑定／struct／enum 为 E1202，浮点标量 `Box` 载荷为 E1201（与整数字面量同码）；未列名成员（`MIN_10_EXP`／`MAX_10_EXP`／`DIG`／`NEG_NAN` 等）与成员调用仍 E1101；`Box<struct>`／`Box<[T;N]>` 内含命名整型成员（含负值）由 L2s 正式 claim（CS-3，见下）。
- 限定枚举变体构造（L2r 合并后）：单层 `E::V(args...)`（含零实参 `E::N()`）为已支持形态；`E` 须为已声明枚举、`V` 须属于该枚举，实参按裸变体既有规则检查，结果类型为该枚举。输出与裸变体逐字节一致（`E::V(1.5)`→`V(1.5)`、`E::N()`→`N`、`Outer::O(Inner::I(1))`→`O(I(1))`），枚举名不进输出；位置与裸变体同矩阵（标量／绑定／struct 字段／数组／元组／多实参／既有嵌套／enum-in-enum），不新增位置。同名变体跨枚举时，限定路径解析到指定枚举；裸变体首匹配行为不变（本切片不新增歧义诊断）。单位变体作值 `E::W`（无括号）不纳入，仍 E1101；零载荷一律写 `E::W()`。括号化 callee `(E::V)(1)` 属既有 parser 泛化，不宣称、不单测。裸 `E::V`（无调用括号）、多级路径／模块／关联项／关联函数／非枚举限定／未知枚举／未知变体 → E1101；不引入新的 `Type::member` 语义（`f32|f64::` 常量成员行为零回退）；实参个数不符 E1601、跨宽 E1201、整型→浮点 E1202、bool→浮点 E1201（均沿用）；`Box<enum>`（L2t 常量子集除外）／含 enum 字段／元素的 Box／嵌套 Box／变量载荷／反方向 N-217／218 维持 fail-closed（限定形式不得绕过）。E1101 编目保持 30；L2r 切片内 ⑤（Box 常量性边界）／②（`Box<enum>`）不纳入（⑤ 见下 L2s；② 单独排期）。
- Box 常量性边界（L2s 定义切片）：本版为定义切片——**无新增语言能力、编译器行为不变、`compiler/src` 零 diff**；只把既有 Box 常量载荷行为固化为 claim／负控与文档。**claim（CS-1～CS-4）**：CS-1 标量 `Box<T>` 8 整型宽度（整型字面量、具名整型成员含负值、无标注 `box 1`／`box (1)`、常量重初始化、Box→Box 移动；直接 `box -N` 不 claim）；CS-2 标量 `Box<f32>`／`Box<f64>`（有限浮点含负值与 `-0.0`、六个特殊值、命名有限常量、常量重初始化）；CS-3 `Box<struct>`／`Box<[T;N]>` 常量树（叶子＝8 整型宽度含复合内负值与具名整型成员、`bool`、`f32`／`f64` 含特殊值与命名常量；节点＝struct／定长数组／任意嵌套／struct 数组／struct 内数组／空数组；常量树重初始化）；CS-4 源形态仅字面量／具名常量（变量／表达式 fail-closed；无标注仅整型字面量，默认 `i64`）。**fail-closed（FC-1～FC-10，冻结）**：变量载荷（含变量重初始化）／表达式载荷／直接 `box -N`／嵌套 Box／Box 字段／Box 数组／`Box<enum>`（L2t 常量子集除外）／enum 字段／enum 元素／tuple／unit／`Box<bool>`／`Box<byte>`／`Box<unit>`／`Box<[byte;N]>`／无标注浮点／struct／array／跨宽与范围不符／一元负号作用于特殊值，均维持既有拦截；允许既有 token（`let 类型标注`／`box 载荷非整型字面量`／`box 载荷须为字面量常量`／`赋值语句`），不新增 E 码。**六项边界不对称**（`box -1` vs `S{f:-1}`、`Box<bool>` vs `Box<[bool;3]>`、`Box<[u8;N]>` vs `Box<[byte;N]>`、无标注整型 vs 浮点／struct／array、`Box<f64>←整型成员` E1201 vs 字段浮点 E1202、`Box<?>` 显示）中，除 `Box<?>` 显示已由 L2u 收敛（D2）外，其余五项按裁定冻结、不在本切片修复；`Box<enum>`／含 Box 枚举载荷归 ②（L2t 常量子集见下；其余仍归 ②）；`Box<?>` 显示与 `check.rs:654` 括注已由 L2u 处理（见下）；变量载荷／嵌套 Box 维持 fail-closed。
- `Box<enum>` 常量枚举载荷子集（L2t 合并后）：标注绑定 `let b: Box<E> = box V(...)`／`box E::V(...)` 可承载编译期常量枚举值——零／单／多字段，字段仅标量（8 整型／`bool`／`f32`／`f64`＋有限浮点／特殊值／命名有限常量／整型成员常量含负值）；C 端以 tag＋union（variant payload structs，零载荷变体占位）承载；`println(*b)` 输出与裸枚举值逐字节一致（枚举名不进输出），并支持多 Box 独立打印、Box 移动、常量重初始化、`unbox`、作用域 drop 一次；不递归析构。fail-closed：变量／表达式枚举载荷、嵌套 Box（`Box<Box<E>>`）、Box 复合含 enum（struct 字段／`Box<[E;N]>`）、enum 变体含 struct／array／enum／Box 字段（含 enum-in-enum 与递归 drop）、tuple／unit、无标注 `let b = box V(...)`、`let v=*b`／`println(b)`／`println((*b,1))` 维持既有拦截；类型／宽度不符沿用 E1201／E1202／E1601，重复 unbox／unbox 后使用 E2301、移动后使用 E2101。`box W(1)` 在 L2t 时为双码 E1201＋E1101（未知变体 E1101、Box 标注 E1201）；该双码与 `Box<?>` 显示已由 L2u 收敛为仅 E1101（见下）。ASAN 第二 manifest 6+3=9（K=3；l2k 原 6 例零改、默认 manifest 48／41／7 零改）；Ret=6（N-146／N-203／N-231／N-254／N-287／N-303，仅执行面）；不新增 E 码／关键字／运行期库／GC，E1101 编目保持 30。
- 诊断文本层（L2u 合并后）：本版为诊断文本层——**无新增语言能力、无新增 E 码／关键字／AC、无运行期行为变化**。D1：`check.rs` 一元负号拒绝特殊值文案改为 `一元 '-' 不接受特殊值 '{ty}'（含绑定后读取）`；E1201 与测试依赖前缀「一元 '-' 不接受特殊值」保留；删除「仅直接打印」陈旧括注，12 条既有 D1 用例仅文本变化。D2：`compatible()` 对 `BoxTy(Bad)` 做诊断归并——载荷检查已返回 `Ty::Bad`（必伴随既有诊断）时不再派生外层 `Box<?>` 不匹配——`Box<i64> ← f64::NAN`／`f64::MAX` 仅 E1202；`Box<E> ← W(1)`／`X::V(1)` 仅 E1101；跨宽 `Box<f32> ← f64::NAN` 单条 E1201；合法 Box 不匹配仍 E1201（`Box<f64> ← 1024`、`Box<A> ← B::V(1)`、跨宽）；`Ty::Bad` 全局 `?` 显示不变。D3/D4：`box W(1)` 收敛为仅 E1101（N-344 单 ID 执行面覆盖 E1201→E1101）；N-290 仅接受 `box 载荷须为字面量常量`（删除旧 `let 类型标注` 兼容 token）；历史 TSV／baseline 字节零改、均不退休。D5：`compiler/scripts/e1101_catalog.sh` 期望 29→30，E1101 发点编目仍 30（lexer 3／parser 20／check 7）。T-4 结构／render／JSON 六键／line-col 不变、无 golden 更新；ASAN 6+3 不变；P=0／Q=10／Ret=0、17 基线；零 tag／Release。

## CI 接线

`ci/run_ci.sh` 的 stage_cargo 检测到本目录 `Cargo.toml` 即自动激活（cargo build+test 入门禁）。compile 阶段经 `ZORC_BIN` 指向本二进制（如 `compiler/target/debug/zorcc` 或安装路径）；内部溢出模式覆盖位由 CI 注入，用户文档不展开。
