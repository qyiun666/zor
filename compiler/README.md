# compiler — 参考实现入口（zorcc）

OQ-1 定论=方案 B（评审 3/3 通过）：过渡实现用 Rust 编写，后端走 C 代码生成；0.2.x 以 C11 后端落地首片、后续可替换。本目录即该实现的 Cargo 工程。

## L2z 合并后现状（0.3.25）：R1／R2 前端检查＋C11 后端；typed Box 8 整型宽度、f32／f64 源形态与复合承载、Box<float> 特殊值载荷、Box 常量载荷（struct／定长数组／有限浮点标量）、枚举单载荷与多字段特殊值字面量直接形式、嵌套复合中的枚举值直接特殊值形式、六个命名有限浮点常量（MAX／MIN／EPSILON）、`MIN_POSITIVE`（f64／f32）、十个整型成员（MAX_EXP／MIN_EXP／MANTISSA_DIGITS／DIGITS／RADIX × f64／f32）、单层限定枚举变体构造（`E::V(args...)`，含 `E::N()`）、Box 常量性边界定义切片（claim 固化；无新增语言能力）、`Box<enum>` 常量枚举载荷子集（标注绑定；tag＋union；不递归析构）、诊断文本层（D1 文案／D2 `Box<?>` 收敛／D3–D5 执行面与工具修正；无新增语言能力）、`Box<enum>` 变量枚举载荷＋变量重初始化（Copy；标量字段；不递归析构）、Box 常量复合树含 enum 叶子（常量-only；标量字段；不递归析构）、Box 一层变量复合 enum 叶（Copy；直接字段／元素；不递归析构）、Box 任意既有嵌套变量复合 enum 叶（Copy；任意既有深度；不递归析构）、Box 复合树内变量标量叶（⑤d；运行期 i64／u8／u32＋编译期标量常量；Copy；任意既有深度；不递归析构）

- 整型常量成员（L2q 合并后）：十个编译期整型常量——`f64::MAX_EXP`（1024）／`f64::MIN_EXP`（-1021）／`f64::MANTISSA_DIGITS`（53）／`f64::DIGITS`（15）／`f64::RADIX`（2）、`f32::MAX_EXP`（128）／`f32::MIN_EXP`（-125）／`f32::MANTISSA_DIGITS`（24）／`f32::DIGITS`（6）／`f32::RADIX`（2）；按整数字面量语义接入：无标注默认 `i64`，有整型标注时向目标类型收敛，标量输出与同值十进制字面量逐字节一致；可用于标量／绑定／`Box<T>` 标量整型载荷（含负值）／枚举载荷／struct／数组／元组／多实参及上述位置的既有嵌套（A 档）。`MIN_EXP` 值本身为负；既有整型一元负号／算术沿用（不是新增能力）。整型成员→浮点标注：绑定／struct／enum 为 E1202，浮点标量 `Box` 载荷为 E1201（与整数字面量同码）；未列名成员（`MIN_10_EXP`／`MAX_10_EXP`／`DIG`／`NEG_NAN` 等）与成员调用仍 E1101；`Box<struct>`／`Box<[T;N]>` 内含命名整型成员（含负值）由 L2s 正式 claim（CS-3，见下）。
- 限定枚举变体构造（L2r 合并后）：单层 `E::V(args...)`（含零实参 `E::N()`）为已支持形态；`E` 须为已声明枚举、`V` 须属于该枚举，实参按裸变体既有规则检查，结果类型为该枚举。输出与裸变体逐字节一致（`E::V(1.5)`→`V(1.5)`、`E::N()`→`N`、`Outer::O(Inner::I(1))`→`O(I(1))`），枚举名不进输出；位置与裸变体同矩阵（标量／绑定／struct 字段／数组／元组／多实参／既有嵌套／enum-in-enum），不新增位置。同名变体跨枚举时，限定路径解析到指定枚举；裸变体首匹配行为不变（本切片不新增歧义诊断）。单位变体作值 `E::W`（无括号）不纳入，仍 E1101；零载荷一律写 `E::W()`。括号化 callee `(E::V)(1)` 属既有 parser 泛化，不宣称、不单测。裸 `E::V`（无调用括号）、多级路径／模块／关联项／关联函数／非枚举限定／未知枚举／未知变体 → E1101；不引入新的 `Type::member` 语义（`f32|f64::` 常量成员行为零回退）；实参个数不符 E1601、跨宽 E1201、整型→浮点 E1202、bool→浮点 E1201（均沿用）；`Box<enum>`（L2t 常量子集／L2v 变量载荷除外）／含 enum 字段／元素的 Box（L2w 常量复合树／L2x／L2y 变量叶除外）／嵌套 Box／非枚举变量载荷／反方向 N-217／218 维持 fail-closed（限定形式不得绕过）。E1101 编目保持 30；L2r 切片内 ⑤（Box 常量性边界）／②（`Box<enum>`）不纳入（⑤ 见下 L2s；② 单独排期）。
- Box 常量性边界（L2s 定义切片）：本版为定义切片——**无新增语言能力、编译器行为不变、`compiler/src` 零 diff**；只把既有 Box 常量载荷行为固化为 claim／负控与文档。**claim（CS-1～CS-4）**：CS-1 标量 `Box<T>` 8 整型宽度（整型字面量、具名整型成员含负值、无标注 `box 1`／`box (1)`、常量重初始化、Box→Box 移动；直接 `box -N` 不 claim）；CS-2 标量 `Box<f32>`／`Box<f64>`（有限浮点含负值与 `-0.0`、六个特殊值、命名有限常量、常量重初始化）；CS-3 `Box<struct>`／`Box<[T;N]>` 常量树（叶子＝8 整型宽度含复合内负值与具名整型成员、`bool`、`f32`／`f64` 含特殊值与命名常量；节点＝struct／定长数组／任意嵌套／struct 数组／struct 内数组／空数组；常量树重初始化）；CS-4 源形态仅字面量／具名常量（变量／表达式 fail-closed；无标注仅整型字面量，默认 `i64`）。**fail-closed（FC-1～FC-10，冻结）**：非枚举变量载荷（含变量重初始化）／表达式载荷／直接 `box -N`／嵌套 Box／Box 字段／Box 数组／`Box<enum>`（L2t 常量子集／L2v 变量载荷除外）／enum 字段／enum 元素（L2w 常量复合树／L2x／L2y 变量叶除外）／tuple／unit／`Box<bool>`／`Box<byte>`／`Box<unit>`／`Box<[byte;N]>`／无标注浮点／struct／array／跨宽与范围不符／一元负号作用于特殊值，均维持既有拦截；允许既有 token（`let 类型标注`／`box 载荷非整型字面量`／`box 载荷须为字面量常量`／`赋值语句`），不新增 E 码。**六项边界不对称**（`box -1` vs `S{f:-1}`、`Box<bool>` vs `Box<[bool;3]>`、`Box<[u8;N]>` vs `Box<[byte;N]>`、无标注整型 vs 浮点／struct／array、`Box<f64>←整型成员` E1201 vs 字段浮点 E1202、`Box<?>` 显示）中，除 `Box<?>` 显示已由 L2u 收敛（D2）外，其余五项按裁定冻结、不在本切片修复；`Box<enum>`／含 Box 枚举载荷归 ②（L2t 常量子集／L2v 变量载荷／L2w 常量复合树／L2x／L2y 变量叶见下；其余仍归 ②）；`Box<?>` 显示与 `check.rs:654` 括注已由 L2u 处理（见下）；非枚举变量载荷／嵌套 Box 维持 fail-closed。
