# R2 所有权/借用子集（规范初稿）

状态：draft｜负责人：核心工程师｜需求来源：PRD §8 R2

## 大纲

1. 唯一 owner；赋值即移动，move 后原变量不可用
2. 借用判定表：同一时刻 多 `&T` XOR 一个 `&mut T`（词法作用域内检查）
3. 子集约束：0.1.x 无生命周期标注语法；跨函数返回引用禁止（只可返回所有权转移值或 Copy 类型）
4. drop 顺序：作用域逆序；无自定义 Drop 钩子
5. 堆分配：Box 式独占所有权句柄
6. 明示限制：无 Rc/Arc → 循环引用无法释放（写入"不可表达程序清单"，AC-R2-1）
7. "0.1.x 可表达 / 不可表达" 程序清单

## 测试用例映射（tests/specs/）

- 借用违规负例 ≥15 条（double free、悬垂、mut 冲突）：`negative/r2-*.zor`，编译期拦截率须 100%（AC-R2-2）
- 正例集运行期过 ASAN 对等校验零报告（AC-R2-3，与工具链 CI 衔接）
- 与 Rust 同题零标注对照样例（AC-R2-4）：`positive/r2-*.zor`
