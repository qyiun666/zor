# R2 所有权/借用子集 规范

状态：0.1.1 冻结基线（原 draft-0.1；实现+16 负例+golden 28 已全入 main，随 0.1.1 发布链定版）｜负责人：核心工程师
需求来源：PRD §8 R2（AC-R2-1/2/3/4 唯一编号来源）。类型层前提见 r1-type-system.md（尤其 §5 移动/复制表、§3 引用类型合规位置）。
本文件为规范性文档，措辞"必须/不得/可以"对应 MUST/MUST NOT/MAY。

## 1. 所有权模型

- 每个**非 Copy** 值在任一时刻恰有一个 owner（绑定或容器槽位）。Copy 集判定沿用 R1 §5，复制不产生所有权问题。
- 移动点：`let b = a;`、实参传递、返回值、赋值 `b = a;`、移入 channel（R3）/移入 FFI（R4）。移动后 `a` 进入**未初始化态**，再使用=编译错误 E2101。
- 部分移动：struct/元组字段可单独移出，移出后整体不可再整体使用（仅可继续访问其余字段），再赋整值恢复。
- `&T` 共享引用、`&mut T` 独占引用：创建即借用，借用结束=词法作用域块尾（无生命周期标注语法，见 §4）。

## 2. 借用判定表（AC-R1-1 引用位置合法 + 本节规则，判定完备无留白）

同一 owner 值 `v` 上，任一程序点允许的引用组合：

| 已持有 | 再创建 `&v` | 再创建 `&mut v` |
|---|---|---|
| 无 | 允许 | 允许 |
| ≥1 个 `&v`（活跃） | 允许 | **禁止 E2202** |
| 1 个 `&mut v`（活跃） | **禁止 E2201** | **禁止 E2202** |

- 活跃性：借用句柄自创建处到其所在块尾均活跃；句柄最后使用后提前失活（NLL 式词法近似：0.1.x 采用**块尾失活**，不做流敏感死变量收窄——差异写入不可表达清单 §7 第 8 条）。
- 引用不得逃逸出借用者作用域（R1 §3 已禁引用入容器类型）；存疑逃逸判定：引用创建与任何可能逸出的赋值/返回之间由 §4 禁则切断。
- 对 `&mut` 指向值再次借用须先结束原借用（重新进入外层块等结构手段）。

## 3. 释放（drop）

- 每个非 Copy 绑定在其作用域结束时按**声明逆序** drop；移动出去的绑定不 drop。
- drop=所有权终结+内存释放（栈帧内），**无自定义 Drop 钩子**（0.2.x 再议）；析构顺序可测（正例用例打点验证）。
- 分支/循环中多路径绑定：以静态可达块分析判定，任一路径 drop 后另一路径使用=E2101。

## 4. 子集约束（0.1.x 硬边界，比 Rust 更少的标注负担）

- **无生命周期标注语法**：任何 `<'a>` 形式在 0.1.x 是语法错误 E1501（R1 码表共用）。
- **禁止返回引用**：`fn` 返回类型不得含 `&T`/`&mut T`（E1502）。可返回：所有权转移的值（含 moved 进 return 的绑定）、Copy 值、元组/struct 组合、unit。
- 输入侧：参数可收 `T`（转移）、`&T`、`&mut T`；被调方对引用参数仅得局部使用，不得保存后影响调用方（保存进全局=禁止，0.1.x 无 `static mut`）。
- 结构体持有引用字段禁止（R1 §3）；因此不存在类型级生命周期参数。

## 5. 堆分配：Box 式独占句柄

- 内置类型 `Box<T>`（具名句柄，非泛型语法开放——0.1.x 以语言级内建操作提供，泛型语法留 0.2.x；OI-3 拼写已定，0.1.1 实现期，D-020 团队自决）：构造=`box expr`（前缀关键字，唯一构造形式）；解引用读写=`*expr`；字段糖=`b.field` 自动借用；交出所有权/释放=`unbox b`（此后句柄使用=E2101）。
- 规则：`Box<T>` 非 Copy、赋值即移动；`*b` 解引用读写；`b.field` 自动借用（只读=`&`，写=`&mut`，受 §2 判定表约束）；owner 作用域结束自动释放。
- 释放后使用：unbox 后原句柄=E2101；句柄 move 进 channel/FFI 后本地再使用=E2101（R3/R4 联动）。

## 6. 运行期内存校验（AC-R2-3 的规范承诺）

- 规定：通过本 spec 正例集的程序在 ASAN 对等校验下**必须零报告**（无 use-after-free / double-free / leak-on-exit——0.1.x 允许 arena 式退出泄漏豁免需显式标注，默认不允许）。
- 实现路径按 OQ-1 方案 B：生成 C 后由 clang/ASAN 执行，跑在 CI（工具链维护），零报告判定进 QA 门禁报告（评审 GQ-1 已决）。

## 7. 可表达/不可表达程序清单（AC-R2-1）

**可表达**：树/链式结构经 `Box` 递归堆、函数内借用传参、move 语义的资源交接、pipeline 跨 channel 移交所有权（R3）、返回新分配 `Box<T>`。

**不可表达（0.1.x 明确拒绝，编译期报错）**：
1. 返回局部/借用值的引用（E1502）；
2. struct/enum/数组持有引用字段（E1501）；
3. 自引用 struct（同上，且返回引用禁令切断构造路径）；
4. 全局可变状态（无 `static mut`）；
5. 闭包捕获（无闭包，OI-2）；
6. `&mut` 双句柄别名（E2202）；
7. 流敏感提前失活（0.1.x 块尾失活，Rust 可写而本语言拒绝的近邻写法入负例 r2-n14/n15）。

**已知限制（可编译、非编译期拦截，spec 层面声明，F-1 修订）**：
- 循环引用无法释放（无 Rc/Arc）：此类程序合法编译并运行，表现为**内存泄漏而非不安全**，ASAN 泄漏报告会捕获——因此**不得**放入 negative/ 集（负例判据是编译期失败，放进去恒假报警）；文档级说明放正例 `r2-leak-note`（M1 起以基准/ASAN 记录呈现，不进门禁失败面）。

## 8. 编译期诊断码表（负例判据载体）
