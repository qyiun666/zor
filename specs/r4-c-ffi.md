# R4 C FFI（规范初稿）

状态：draft｜负责人：核心工程师｜需求来源：PRD §8 R4（P1，R1–R3 全绿前可规范先行）

## 大纲

1. `extern "C" fn` 声明，C ABI 调用约定/命名
2. 类型映射表：整型族、byte、unit、`Handle<T>`（不透明指针句柄，禁止算术）、固定数组退化为指针参数
3. unsafe 边界：FFI 调用必须位于 `unsafe` 块内
4. 0.1.x 不做 C→ZOR 回调（OQ-4：不提入，待评审确认）
5. 边界：所有权转移进 FFI 后继续使用原变量 → 编译期拦截；C 错误码不做魔法转换

## 测试用例映射（tests/specs/）

- 正例：strlen / qsort 调用 + 1MB 零拷贝缓冲写读一致（AC-R4-2/3）
- 负例 ≥5 条 FFI 误用，编译期拦截率 100%（AC-R4-2）
