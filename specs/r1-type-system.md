# R1 最小类型系统（规范初稿）

状态：draft（0.1.0 tag 前完成初稿）｜负责人：核心工程师｜需求来源：PRD §8 R1

## 大纲

1. 原始类型：i8/i16/i32/i64、u8/u16/u32/u64、f32/f64、bool、byte、unit
2. 组合类型：固定长度数组 `[T;N]`、元组、struct、enum（标签联合，不含递归变体）
3. 引用类型：`&T` / `&mut T`（仅出现在 R2 规则内，形式规则见 r2-ownership.md）
4. 函数：显式签名、单返回值（多值用元组）
5. 字面量推断：整型默认 i64、浮点默认 f64；隐式数值转换禁止
6. 赋值/移动语义表（AC-R1-1 要求，无未定义行为留白）
7. 溢出行为：待 OQ-2 关闭（候选：debug checked / release wrap）
