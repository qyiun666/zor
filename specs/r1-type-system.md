# R1 最小类型系统 规范（初稿 draft-0.1）

状态：draft-0.1（0.1.0 tag 前置项 V-2）｜负责人：核心工程师
需求来源：PRD §8 R1（AC-R1-1/2/3 唯一编号来源）；OQ-2 工程口径=评审通过项（终审语义 M3 落定）。
本文件为规范性文档（normative）。措辞"必须/不得/可以"分别对应 MUST/MUST NOT/MAY。

## 1. 类型宇宙总则

类型的形成规则（WFT, well-formed types）：

```
T ::= prim | [T; N] | (T1, ..., Tk), k ≥ 0 | struct | enum | &T | &mut T | fn(...) -> T
```

除此形式外的类型表达式在 0.1.x 不存在（无泛型、无 trait bound、无 `*const T` 用户语法，FFI 指针仅 `Handle<T>`，见 R4）。

## 2. 原始类型 prim

`i8 i16 i32 i64 u8 u16 u32 u64 f32 f64 bool byte unit`

- `byte` 为独立 8-bit 无符号类型，**不**等同于 `u8` 的别名（可互转但须显式转换函数，见 §5）。
- `unit` 是唯一零大小类型，字面量 `()`。
- 无 `char`/字符串原语：字符串字面量类型为 `[byte; N]`（UTF-8 字节序列，0.1.x 不含独立字符串类型，见开放项 OI-1）。

## 3. 组合与引用类型

- **固定长度数组** `[T; N]`：N 为编译期字面量整型；N=0 合法；元素类型必须 WFT。
- **元组** `(T1,...,Tk)`：k=0 等价 `unit`；不可变长。
- **struct**：具名字段记录；字段类型必须 WFT；0 字段 struct 合法。无继承、无方法体（函数以 `fn` 独立定义并以首参接收 `&T/&mut T/T`，语法糖 0.2.x 再议）。
- **enum**：标签联合。变体形态仅两种——无字段变体 `A` 或元组变体 `A(T1,...,Tk)`。**递归禁止**：变体载荷类型不得（经任意传递链）引用该 enum 自身（如 `List = Cons(List) | Nil` 在 0.1.x 不可表达，堆递归需 Box 亦未开放，列入不可表达清单 R2 §7）。
- **引用类型** `&T` / `&mut T`：只能作为函数参数/局部绑定出现；不得存入 struct/enum 变体/数组元素（防逃逸，与 R2 词法作用域检查闭合）。形式规则与生命周期见 r2-ownership.md。

## 4. 字面量与推断

- 整型字面量默认 `i64`；浮点字面量默认 `f64`；`true/false : bool`；字节串字面量 `"[T;N]"` 型。
- 推断自上下文单向收敛：绑定/参数/返回任一处显式标注即固定；**禁止隐式数值转换**——`let x: i32 = 1;` 合法（字面量适配），`let y: i32 = some_i64;` 编译失败（E1201 类型不匹配）。跨类型运算须显式转换函数（`i64.to_i32()` 类内置，0.1.1 实现清单）。
- 算术/比较运算仅在操作数类型相同时合法；结果类型=操作数类型。

## 5. 赋值/移动/复制语义表（AC-R1-1，无留白）

| 类型 | `let b = a;` / `a` 作实参 | 复制方式 |
|---|---|---|
| prim（含 byte/unit） | 复制（bit-copy），a 仍可用 | 隐式 |
| `[T;N]`、元组、struct | 全部成员属 Copy 集 → 复制；否则移动 | Copy 集=成员全为 prim/`()`/递归 Copy 的数组/元组/struct |
| enum | 全部变体载荷属 Copy 集 → 复制；否则移动 | 同上 |
| `Box` 式句柄（R2 §5） | 移动 | 仅显式深拷贝函数（0.1.x 内置类型逐个定义） |
| `&T` / `&mut T` | 复制句柄本身（引用可 Copy），**不**复制指涉对象；`&mut` 复制后原句柄失效（unique-move 语义，归 R2 判定表） | 见 R2 |
| `Handle<T>`（R4） | 移动 | 禁止算术与复制 |

移动后原绑定再使用=编译错误 E2101（R2）。Copy 判定不设用户可标注接口（无 trait），由上述结构规则决定。

## 6. 函数

- 显式签名：`fn name(p1: T1, ..., pn: Tn) -> R`；无 `R` 时视为 `-> unit`。
- 单返回值；多值用元组。重载不存在；名字作用域=模块级唯一。
- 递归允许（调用图无静态限制；栈溢出为运行期错误，0.1.x 不做深度检查）。
- 一级函数：可作参数/返回值的仅 `fn` 名（函数指针语义，同签名可比）；闭包表达式 0.1.x 不提供（与 R3 spawn 捕获规则联动，见开放项 OI-2）。

## 7. 溢出与边界行为（Edge cases，PRD v1.1 勘误归本节）

- 整型算术溢出：**debug 构建 checked**（每次算术生成运行期检查，溢出=运行时终止错误 E30xx 类，带源行号），**release 构建 wrap**（模 2^N 回绕）。工程实现按 OQ-1 方案 B 用 C 内建 `__builtin_*_overflow`，零额外运行时依赖。
- 除零：debug/release 一致，运行期终止错误。
- `f32/f64` 不适用溢出语义；IEEE754 行为直通（NaN 不视为错误）。
- 终审口径 M3 落定（D-012）；本节措辞已按 debug checked / release wrap 成文，若终审变更须同步升 draft-0.2 并触发 T-5 用例修订。

## 8. 编译期诊断要求（负例判据载体，AC-R1-2）

每个类型错误必须输出：`错误码(E1xxx) + 源文件:行:列 + 错误类型名 + 一句事实描述`。最小码表：

E1101 未知类型名｜E1201 类型不匹配｜E1202 隐式转换禁止｜E1301 数组长度非编译期常量｜E1401 enum 递归变体｜E1501 引用类型不合规出现位置｜E1601 函数签名/实参不一致。

错误文案为黄金文件基线（门禁 T-4），改动走 PR+QA 评审。

## 9. 测试用例映射（AC-R1-2：≥20 正 + ≥10 负）

目录基准（M-1 定论）：`tests/specs/positive/r1-*.zor`、`tests/specs/negative/r1-*.zor`（编号即用例 ID，M1 起落文件）。

- 正例 r1-01…r1-20：prim 全声明、[T;N] 含 N=0、元组 0/2/3 元、struct 0 字段/多字段、enum 无字段/元组变体、`&T`/`&mut T` 参数、函数签名含 unit 返回、Copy 表逐行覆盖、字面量推断收敛、显式转换函数。
- 负例 r1-n01…r1-n10：未知类型、i64→i32 隐式、操作数类型不等、数组长度非常量、enum 直接/传递递归、引用进 struct 字段、实参/返回签名不符、移动语义误用于 Copy 判定（结构性非法）。每条对应 §8 一个错误码。
