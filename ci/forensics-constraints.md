## 原则（一句，统摄七款）

**可复算性**：凡向他席呈出的值或断言，他席须能用**同一式子、同一载体**复算出同串或同状态。不能复算的，按未证处理，不得据以判绿、判差、判"已做"。

七款的失效面：①读数被管道改写｜②输入被 shell 改写｜③对象串无式可复、层级错配｜④引用源无法核对｜⑤动作／状态断言无载体锚（"说做了"不可核）｜⑥核不回来时滑成否定式断言｜⑦做判定时所读的原值未并印。

## 款①｜退出码禁过管道

`"$BIN" "$@" >"$o" 2>"$e"; rc=$?`，随后再读 `$e`／`$o`。禁任何把 `$?` 与目标进程分离的写法（`| tee`、`| head`、命令替换嵌套等）。
病因：管道后 `$?` 是末段命令的退出码。实例＝本窗执行席自查（`if` 两形经管道取到假 `rc=0`，去管道真值 `rc=1`）。

## 款②｜多枚 argv 逐枚分列，禁依赖 shell 对未引号变量的分词

`run(){ "$BIN" "$@"; rc=$?; }`，实参一律作独立 argv 传入；脚本首行显式声明解释器（`#!/usr/bin/env bash`），复现时以声明为准。
病因：zsh 不对未引号变量做词分裂、bash 会。它改变的是**被测程序的输入**，比款①隐蔽——rc 可能碰巧对而诊断句归因错位。
实例三枚（同形不同人）：① 执行席自查——`-o 未实现` 却报 `未知选项 '-o out.bin good.zor'`，rc 碰巧对而诊断句归因错位；② 判据位自证——zsh 下 `grep --include=*.md` 因 glob 无匹配整命令失败，同式入 bash 正常；③ 文档席自证——把整串 argv 塞进单个未引号变量又在 zsh 直跑，短路三组合形取到 **rc=2／stdout 空**的假值，与在册锚相反；改 bash＋argv 逐枚分列重跑才得现值。③ 是本款**第一枚改变业务结论**的实例，为主例。
附条：负例基线一类**必须在仓库根以相对路径跑**（golden 体内嵌路径串），否则逐字节比对必假失败。

**款② 名下口径注**：凡切片／区间取串，必以**直管式**一次取到哈希（`git show ${REF}:<path> | awk … | shasum -a 256`），不得经 `$( … )` 或 shell 变量往返——命令替换剥离尾部换行，行数与 sha 同拍失真。`${REF}:path` 花括号形是本口径注与款⑦ 共同的**取径前置**（先取得到值，才谈得上并印）。

## 款③｜呈对象串必随标三段：算式、式别、复算路径＋可达性

- **算式**：逐字给出可粘贴执行的式子（含排序、分隔、截断位数）。
- **式别**：`blob`／`tree`／`commit`，三者不得互称，不得跨式别比同异。位数必随算法随标，不写死一个数（commit 面 SHA-1 与摘要面 SHA-256 不同尺）。
- **复算路径＋可达性**：给出取径命令，并明写该对象在**核验者侧是否可达**；仅呈方单点可取时明写「单点可取」，且结论须另附一条**人人可达的等价式**，否则降为线索。
- 判差前置：他席值与本席值不同串时，**先核对三段是否同**；同式同别仍不同串才判差并报差。
- 列序呈现形见款⑦c（指路，不重述）。

**示例位 A（真·同值异串）**：golden 聚合零变而三席三串——口径甲 `cat $(ls golden/*.txt|sort)|shasum -a 256|cut -c1-16`、口径乙「逐件 sha256 摘要列再聚合」、执行席值（未随标算式）、文档席值（已随标算式与式别＝blob 内容聚合、非 git tree）。四串不同而结论一致；病灶只是未标算式。主判据一律取逐字节比对，聚合值仅作辅证。

**示例位 B（不同式别的对象本就不该同串）**：曾被并列表述为"同值异串"的两串，实为**拿 commit 串比 tree 串**：其一为 commit 且仅呈席 clone 可达（单点可取），其一为 tree（人人可取，式＝`git rev-parse <合入前 head>^{tree}`）。该例**不属**款③ 的"同值异串"，属链判据的适用条件问题。

**通用核对式（按适用序，见末节表）**：
- 合入**已发生**：首选三段 `git diff --name-only`（票1↔main、票2↔main、base↔main），三式齐 ⇒ main 载荷集恰等两支并集。
- 合入**未发生**或需预判：加强式 `git merge-tree --write-tree <票序两支 head>` 首行 tree ＝ `git rev-parse <合入后 main>^{tree}`，即"合入后 main 内容体恰等于各票载荷按票序的合成结果、零第三方内容"。本式实测三特性：同式两跑同串、换序同串、**不产生 commit、不写任何 ref、工作树零脏** ⇒ 完全人人可达。

**③ 层级取证律（与下枚四枚子律同格）**

> **③a 资格**：机制层（裸实现探针）读数不得充当被测载体（闸内）的定域证据；但亦不得仅以"层不对"撤销其实质——须经 ③b 的载体复测判定其为真为假。
> **③b 义务与上限**：凡用于定域的读数，须在被测载体上复测；复测范围**限于已被用于定域的那几枚取值**，不扩档、不无限复测。未复测者按「未测档」随标，不得升格为"全部／任意"。
> **③c 枚级归类**：一枚读数的成因层须与他所主张的机制对上；**被更上游一层（归一化、预处理等）解释掉的读数，不计入该机制的证据集**——另列为「载体不可测档」，既不计入正例，也不计入反例。

例证锚（同格附注，不另立条）：段内去空白归一所吸收的取值＝③c（闸内不报由归一化解释，机制层反向读数 ⇒ 摘出域证据集）；"ASCII 印符"形＝③a＋③b（机制层先测、判据位闸内复测后由反向转为为真）；「恒绿」头注＝③b 的反面（未复测即写"恒／都"，量词与覆盖域双失）。层级错配归 ③c，不独立成格。

**四枚子律（合为一格，逐枚不另立）**：

> ① 凡「在该环境下对 X 恒／都 Y」式断言，须随标使 Y 成立的取值域，未标域＝未证；
> ② **收窄量词时须实测"被排除侧"的新档样本**，只复测旧样本不算收窄成立；
> ③ **反例须在被测载体上取**，机制层探针的读数不等于闸内行为；
> ④ 判据措辞钉在**已实测档**，未测档显式标外推，不写"任意／所有"。

**可复算性预检（三面）**——入册任何判据／取证式前的准入检查：

> 式别面——同名多值须四件齐标（起点锚／终点锚／含端与否／行数），防"同名三值"；可执行面——凡跨两次实跑或两名执行者必然不同串的分量，不得作等值判据，防永红闸；环境面——判据取值不得随执行者环境（locale、shell 分词行为、grep BSD/GNU 方言）漂移，防同题异值。

**同式复现佐证力＝1**：两席以同一取径各跑一次得到同一值，佐证力＝1、不是 2；独立佐证的前提是**取径不同或至少逐枚随标取径**，否则只是同一个错误的两次复读。异式同值（遍历域不同的两条式子同值）才使佐证力 ≥2。

**放行后微改后置律（含反向半句）**：

> 双条件之一已落地（票面绑定串已定）之后，凡**非判据面、非用户面**的措辞／注释／格式类微改，一律后置到下一次必要的 head 变更顺带；**不得为微改重开已闭的绑定链**。反向同样成立：若某次改动**必须**动 head，则同批允许把在册的微改一次带齐（一次动、两桩事，别动两次）。

## 款④｜引用他载体文字必随标「全路径＋行号＋是否 DOC-3 权威副本」

三缺其一，该引用**不作判据依据**，只作线索。
病因：同一文档多副本、行号恒差且内容分叉。执行形补句：**未取原件 ⇒ 不作断言，改写作"未核"**——不核对时必须显式写"未核"，否则沉默会被后席读成已核。
凡"扫串／数串"类取证，先 `LC_ALL=C` 再取，或改用逐字节式（`python3`／`cmp`／`shasum`）；未钉 locale 的读数不得作指认他席的依据。

## 款⑤｜动作／状态断言必随标载体锚

凡称"**已入册／已补／已改／已回写／已裁**"，必随标四件：**件路径＋段落或行号锚＋现读 mtime＋关键词 grep 命中数**。
可机械核子句＝**随标 mtime 必须 ≤ 本帖发出时刻**（作者＝产品经理）。不等式一旦违反，先行自述当场可判，不靠事后追认。
**款⑤ 载体面注**：凡经**复制**入册的件，其 mtime **只证「何时被复制」、不证「何时取的值」**；跨复制存活的身份只有 **sha256＋字节数**。⇒ 索引对复制件须写**两行时刻**（取径时刻／复制时刻），后席不得拿复制件的 mtime 当取径时刻（否则＝静默失真）；单刻同值即「一次复制的指纹」，可反查复制批次。连带面：`cmp`／`diff -r` 类字节对同不受影响（比的是字节）；受影响的是「以 mtime 作款⑤ 时序证」的用法——**含 `mtime ≤ 帖时` 机械子句，对复制件此子句失效**，须改用取径时刻或 sha 共现证。落件优先 `mv`（保 mtime）；必须复制时用 `cp -p`；凡 `cp -R` 不带 `-p` 的批，其 mtime 一律不得充当任何时刻断言的载体。
**款⑤ 格言（裁口位裁入本款同格）**：**时刻的载体应在名字里，不应在文件系统元数据里**——RUN_ID 内嵌 UTC 时刻，对 `cp`／`mv`／跨机搬动全部免疫；mtime 一概不免疫。

## 款⑥｜只读面覆盖不到断言范围时，结论只能写「核验不可达」＋已取面清单

不得写肯定，也不得写否定——"核不回来就写否定"与"看起来比实态更已办成"是同一失真向的两面。
样板＝本窗手册登记态案：四只读面均不支持"已登记"，而 catalog 面只覆盖 SOP kind、无"按群列已登记 skill 包版本"的只读入口 ⇒ 判**核验不可达**，不写"确认未登记"。工具面缺口随 0.1.27 报平台侧。

## 款⑦｜并印则（输出面总则；正文入环境面同格）

> **款⑦（并印则）**：凡判定属四类之一——两侧同串／SAME／等值、空集／0 枚／0 行、布尔 YES／PASS／MATCH、前缀／包含——**输出必须带上判别所读的那个原值本身**（两侧现值、样本行、逐行名册，或长度／sha）；**只印布尔值或合计值者该格判「取证不成立」**，它既不是 FAIL 也不是 PASS，不入任何判定汇总。**分工**：款③ 管**输入侧**（这值怎么算出来：算式＋式别＋遍历域＋复算路径与可达性），款⑦ 管**输出侧**（做判定时读到的原值本身）；**⑦c 的正文只入本款**，款③ 内一句指路（「列序呈现形见款⑦c」）不重述——免同一约束两个载体。
> - **⑦a 两侧类**：两侧实值逐枚并印（含字符数／字节数），并各标取径式别；一侧不可取 ⇒ 该格取证不成立，不得以 SAME 覆盖。
> - **⑦b 空值类**：须并印两式——**点名式**（应得 0 行）与**全列式**（应得全集减一），全列式逐行可点名；只报「0 枚」者不成证。
> - **⑦c 聚合类**（列序版）：凡一行多列同类数值的聚合，**必并印所读样本行**并标列号（`test result:` 行 passed＝列 4／failed＝列 6／ignored＝列 8），合计值不单独作证。
> - **⑦d 枚数类**：凡「N 枚同串／N 枚齐／0 枚」类断言，**枚必随标所指对象种类（run 目录／log 件／sha 值／机次）与集合域**；未随标者该格判「计数不可复核」。**等值载体附注**：缩略 sha（前缀＋省略号）**不作等值判据**；在册判等位一律全长并随标取值命令原文，短形只作显示。
> - **⑦e 非空前置**：凡「扫串／数串／取切片」类取证，取到的值**须先证非空再入比对**——**空值不得进入任何等值比对**（两侧同空＝假 SAME，本窗首枚假 SAME 即此形）。三件套＝**先 `LC_ALL=C`；解释器身份随标（zsh／bash 对 `$ref:path` 的展开不同）；空值即停手标"核验不可达"**。两枚在册实测同族：一为未钉 locale 的 one-true-awk 给 61 字符假形（编码层假形），一为 zsh 无花括号取 `$ref:path` 得长度 0／bash 无花括号与 zsh 花括号均得 338（参数展开层空值）——**两条都是"载体没坏、读法坏了"**。
> - **⑦f 行号随 ref**：任何 `path:line` 断言必随标**所取的那个 revision／工作树面**——同一行号在不同 ref 下语义可反（`r2:94` 即例）。这是款④「跨载体引用带全路径＋行号＋是否权威副本」的 **ref 维补全**。
> **反向半句（指路、不并条）**：本则管**输出面**；其反向面＝**比对域只含语义相关分量**（无关变量——PID、时刻、目录名、stdout 总字节——不得进入逐字节比对域）＝裁口位「比对域只含语义相关分量」那格，同一条律的两半句、两个编号各归其主。
> **失因（在册实证）**：zsh 把 `${H}:ci/…` 的 `:c` 解析成参数修饰符 ⇒ `git show` fatal → 下游 `grep -c` 得**假 0** → `diff` 两侧同空得**假 SAME**。一次失配同时造出假零与假绿，抓住它的唯一手段就是并印两侧实值。
> **机次账**：本窗三机次同源（管理席首、裁口位第二、工具链同源）⇒ **同式复现佐证力＝1**，三机次皆当场自纠、假值未落任何在册载体 ⇒ 入案例集不占在册失真账。
> **与款①／款③ 的分工**：款① 管**取值形**（取 rc 不得过管道），款③ 管**聚合值须随算式**，款⑦ 管**该算式所读的原值须同拍并印**——三者不可互替，亦不重复计账。

### 环境面同格（款⑦ 载体格之续）

**locale 声明**：凡取证式对**多字节分隔符**做切分，须二选一：显式钉定 locale（`LC_ALL=en_US.UTF-8` 或等价），或改用按连续序列切的实现（`awk gsub`／`sed`）；两者皆不标者，其聚合值不作在册判据载体。

**切分取径终态**：凡对多字节分隔符做切分，**缺省 (b)**（`awk gsub`／`sed` 按连续序列切，不依赖本机 locale）；**(a) 降为次选，且须附效应证据，否则视同「不标」**。效应证据三句（在册更正形）：

> ① 效应辅证：`LC_ALL=<所钉名> locale charmap` 的回显**须与所钉 locale 一致**（钉 `C` ⇒ `US-ASCII`；钉 UTF-8 ⇒ `UTF-8`）；**不得以 rc 判真伪**（两席实测 bogus 名下 rc=0）。
> ② **终判**：同一份脚本、同一段输出，在两种不同**外层**环境下实跑**逐字节 SAME**（`cmp` 空出）。① 只证"钉上了"，② 才证"钉住了判定"——② 不可省。
> ③ 适用范围＝**凡对非 ASCII 字面量做等值比较或切分**。

**glibc 半断言随标**：涉及 `en_US.utf8` 名形的在册记录一律记「各席本机不可达（本机 `locale -a` utf8 尾形 0 枚），作用面仅 CI 镜像」，不作实测基础句。

**锚定钉（5b 的机械实形，非新闸）**：码表区间逐行首枚取用 `^[[:space:]]*E[0-9]{4}`；登记名须逐字（字符类名后的冒号不可漏，漏则部分引擎 `invalid character class` 响亮失败、部分引擎未实现行为静默放行）。

**阳性对照注入值（code-table 段）**：阳性对照必须选在**能区分修前／修后两态的取值**上——未修头放绿／修后报红，才算两态区分性对照；两态同色的取值（如保留前缀类）只算回归位，不作判别力证据。本节所述注入对照的判据位读数以票面当期有效版为准，路径＋节号随标。

**通道分离通则**：

> 凡"两态必不同"的分量（外层环境名值、`RUN_ID`、PID、时刻），不得进入被逐字节比对的载体。首选**通道分离**（恒定量入留证文件、环境量走自述通道），次选**字段豁免**；开豁免即须同时写死豁免闭集，未列名者视为违规——**豁免面不得由后席单方扩**。

stdout 在本地不落盘：引用日志内 stdout 自述行时须同拍标「取径＝stdout 重定向至 `<路径>`」；平台侧 stdout 自动进 job log，本地不自动。不随标就是一枚"看着有、复算无"的证据。

## 硬落法⑰｜证据件唯一之家（规则句）

> `ci/logs/**` 只存**当次实跑的留数**；跨窗引用的证据件唯一之家＝仓外 `qa-outputs/<窗>/evidence/**`（含 `reports/`），**产品工作树内（即使被 gitignore 的路径）不得存放取证证据件**。在册引用一律走仓外路径。

- 腾空原处三步：**① 逐枚并印 `diff -r`／`cmp` rc → ② 移（撞名则移入瞬态隔离区，不在在册位造第二串）→ ③ 移后就地复算 sha**。
- 保全件目录须分三类标注：在册证据／**0 字节件即断言本体**（其内容即"该取径返回 0 字节"这枚断言，**不得按体量当垃圾清掉**）／预演・已废取径（不作判据，仅留案例样本）。入册位落件后必 `find -mindepth 1 -type d` 证零子目录。
- `LATEST`＝游标非判据；凡引其读数须随标"可能指向已移走的目录"；历窗 `ci/logs/**` 路径自此为历史时点值，只可随标时刻引用、不可作可达路径。
- 规则自入册日生效、**不溯及历窗留数**（规则与执行分两格；历窗留数与本窗 `task/*`、`refs/*` 组归 0.1.27 卫生批，本件不写"整改既有违规"）。

## 短哈希自核形（终形）＋格言

短形**不得手打**，一律现取 `git rev-parse --short=N <全长字面量>`；判别式用 **subject＝全长、pattern＝短形加引号** 的 `case` 式，**下限 7 位**（6 位在本窗已被证可误写成另一种 6 位 ⇒ 册面短形自此 ≥7 位或与全长串共现）；该式不经 `:` 切片，避开参数修饰符陷阱：

```
L=8af47d41365e58830ba2cfa0dc8994001c28ad8d; S=8af47d4; [ "${#S}" -ge 7 ] || exit 1; case "$L" in "$S"*) echo PREFIX-OK ;; *) echo MISMATCH ;; esac
```

为"分开两式"而加的任何 lookbehind，必须先以对抗样本证它不吃真值——**判据只能设计成会多报，不能设计成会漏报**。册面格言：**「纪律若不能写成一条会红的式子，就还没入册。」**
