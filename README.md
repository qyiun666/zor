# ZOR

面向 AI 时代的系统级编程语言：Rust 的所有权安全 + Go 的并发模型与工程效率。

> 当前阶段：**0.1.x 语言核心验证**。本期只交付规格与骨架，不抢跑语言特性实现。
> 需求单一来源：`shared/ZOR-0.1.x需求包-PRD-v1.md`（群共享目录），本 README 只做导航。

## 仓库结构

| 目录 | 用途 | 归属 |
|---|---|---|
| `specs/` | R1–R4 四条语言规范（0.1.x 标准先行） | 核心工程师 |
| `tests/` | 规范测试用例（正例/负例，按 AC-Rx-y 编号） | 核心工程师产出、QA 回归 |
| `bench/` | 三项基准：内存驻留 / 吞吐 / 编译耗时 | 工具链工程师 + QA |
| `examples/` | 最小编译示例（hello 级占位，见 PRD §7） | 核心工程师 |
| `compiler/` | 参考实现入口（待 OQ-1 选型评审后落位） | 核心工程师 |
| `.github/workflows/` | CI 基线（编译 + 单测流水线骨架） | 工具链工程师 |

## 版本规则

顺序递进 `0.1.0 → … → 0.1.99 → 0.2.0 …`；0.1.0 = 仓库骨架 + 四条 spec 初稿合入时打首个 tag。紧急修复以 `0.x.(y+1)` 补丁号发布。

## 协作约定

- 分支开发 + PR 合入主干；强推/删分支须群主批准。
- 规范/测试/基准文档命名与落盘规则见团队手册（zor-team-handbook）。
- LICENSE 采用 MIT；如需调整（如 Apache-2.0 双授权）请在 0.1.0 首个 tag 前于群内提出。
