# ZOR

面向 AI 时代的系统级编程语言：Rust 级的内存安全（编译期所有权检查、无 GC）+ Go 级的开发体验（轻量并发、上手简单）。

> **当前状态**：0.2.0 起进入首个可执行闭环与后续切片，按内部验证节奏推进（每版含真实增量）；0.2.0 为 `hello` 首片可执行闭环（`hello.zor` 可构建并运行）；最新发布版本与说明见 [Releases](https://github.com/qyiun666/zor/releases) 与根目录 `CHANGELOG.md`。
> 诚实声明：0.1.x／0.2.0 各版本均为**内部验证里程碑，非可用语言版本**——参考实现 `zorcc` 自 0.2.0 起为编译前端＋最小 C11 后端，可构建并运行 `hello` 首片原生二进制；完整语言能力、stdlib、跨平台与完整运行期保证仍待后续切片，**不承诺安装或生产可用**。面向外部开发者的试用版最早在 0.5.x Preview 系列出现。

## 看进度

- 各版本发布说明：仓库 [Releases](https://github.com/qyiun666/zor/releases)（逐版更新）
- 变更日志：根目录 [`CHANGELOG.md`](CHANGELOG.md)
- 版本节奏：版本号 `0.1.0 → … → 0.1.99 → 0.2.0 …` 顺序递进；0.1.x 语言核心验证 → 0.2.x 首个可执行闭环（hello 首片起）与后续切片 → 0.3.x 运行期安全、stdout／CLI 契约与复合类型输出（L2a–L2z）→ 0.5.x+ Developer Preview（外部可安装、可试用）。暂不规划 1.0.0。
- 0.3.x 状态：按 L2a–L2z 切片推进，各版均为内部验证里程碑，零 tag／零 Release；其中 0.3.18（L2s）为 Box 常量性边界定义切片（契约固化，无新增语言能力、编译器行为不变），0.3.19（L2t）开放 `Box<enum>` 常量枚举载荷子集（标注绑定），0.3.20（L2u）为诊断文本层（无新增语言能力、无运行期行为变化），0.3.21（L2v）仅开放 `Box<enum>` 变量枚举载荷＋变量重初始化（Copy；标量字段；不递归），0.3.22（L2w）开放 `Box` 常量复合树含 enum 叶子（常量-only；标量字段；不递归），0.3.23（L2x）开放 `Box` 一层变量复合 enum 叶（Copy；直接字段／元素；不递归），0.3.24（L2y）开放 `Box` 任意既有嵌套变量复合 enum 叶（Copy；任意既有深度；不递归），0.3.25（L2z）开放 `Box` 复合树内变量标量叶（⑤d；运行期 i64／u8／u32＋编译期标量常量；Copy；任意既有深度；不递归）；不构成安装或生产可用承诺。

近期里程碑与演示安排以官方发布通报为准，本 README 不维护里程碑看板（避免两处口径漂移）。

## 仓库结构

| 目录 | 用途 |
|---|---|
| `specs/` | R1 类型系统 / R2 所有权 / R3 并发 / R4 C 接口 四条语言规范 |
| `tests/specs/` | 验收测试集：正例、非法写法拦截负例、输出基线（golden） |
| `compiler/` | 参考实现 `zorcc`（R1 类型检查 + R2 所有权/借用诊断 + 0.2.0 最小 codegen 路径；C11 后端） |
| `ci/` | 本地/CI 验证脚本（严格模式：空套件、负例零计数、基线缺失均判失败） |
| `bench/` | 基准脚手架（内存驻留 / 吞吐 / 编译耗时；运行基线待后续切片；0.2.0 不做量化） |
| `examples/` | 最小示例（含可运行的 `hello`；其余仍为编译检查级用例） |
